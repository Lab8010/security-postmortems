# security-postmortems — 国内セキュリティ侵害事例アーカイブ

日本国内で発生し、社会的に注目を集めたセキュリティ侵害を事例ごとに整理するリポジトリです。
**「何が起きたか」だけでなく「なぜ起きたか」「どう立て直し、何を再発防止策としたか」** までをまとめ、
他社の事例から学んで自組織の備えにつなげることを目的としています。

## 情報源の方針（要約）

1. **企業の公式発表（プレスリリース、報告書PDF、決算資料）を最優先**の情報源とし、可能な限りリンクします。公的機関（個人情報保護委員会、総務省、国土交通省など）の公表資料も一次情報として扱います。リンク切れに備え、Web Archive のURLを併記します。
2. 公式に書かれていない情報（攻撃グループ名、報道された会見内容など）は **「報道ベース」** と明記して区別します。
3. 本リポジトリ独自の分析・教訓は **「分析」** として公式情報と分けて記載します。

## 免責

- 各ページの内容は記載の「最終確認日」時点で公開されていた情報に基づきます。その後の続報で変わる可能性があります。
- 攻撃手法の記述は、各社が公表した範囲にとどめています。
