# ニチレイグループ サイバー攻撃によるシステム障害（2026年7月）

> 最終確認日: 2026-09-30 ／ 状態: **調査継続中**。業務は通常稼働に復帰済み。原因・侵入経路・具体的な再発防止策は未公表

| 企業 | 株式会社ニチレイ（影響を受けたのはニチレイロジグループ各社、ニチレイフーズ） |
| 顕在化日 | 2026年7月13日（システム障害が発生） |
| 初期侵入 | 非公表 |
| 攻撃種別 | サイバー攻撃によるサーバーの被害（ランサムウェアかどうかを含め、手口は非公表） |
| 業務影響 | ニチレイロジグループ各社の **冷蔵倉庫の入出庫業務**、ニチレイフーズの **冷凍食品の出荷業務** が停止。影響は日本国内に限られる |

## 3. 攻撃の流れ

**非公表**。同社は「警察および関係機関と連携し、対応を進めているため、サイバー攻撃の詳細は情報開示を差し控える」としている（第4報）。

## 4. 被害・影響

### 4.1 業務・事業

- 被害の拡大を防ぐため、グループ内のシステムを遮断した。その結果、低温物流事業では冷蔵倉庫の入出庫業務が止まり、食品事業では冷凍食品の出荷が滞った。
- 外部のセキュリティ専門会社と安全対策を講じたうえで、7/17から受発注を制限しながら部分的に再開し、7/24に全拠点で平常稼働に戻した。

## 5. 原因

**非公表**（2026-09-30時点）。第7報では「外部専門会社の支援のもと、原因分析および影響範囲の調査を進めている」としている。

## 6. 初動対応

- 発生当日にシステムを **遮断** し、同日に **緊急対策本部** を設置した。
- 外部のセキュリティ専門会社の支援を受けて調査し、安全対策を講じた。
- 警察・関係機関と連携した。
- 受発注を制限したうえで部分稼働 → 制限解除、と段階的に復旧した。

## 7. 再発防止策（公表されている範囲）

現時点で公表されているのは方針レベルのみ。具体策が公表されたら更新する。

- グループ全体のセキュリティ水準の高度化と、監視体制の見直し（第7報）
- システムセキュリティの強化と監視体制の強化を継続（第6報・第7報）
- 万一の事態でも影響を最小限に抑えるよう、**事業継続計画（BCP）をさらに見直す**（第7報）
- 外部の専門会社と連携してサイバーセキュリティ対策を強化（決算説明資料）

## 9. 分析: この事例から学ぶこと（暫定）

原因が公表されていないため、現時点では **対応面** からの学びに限られる。

- **復旧の速さ**：発生から4日で部分再開、11日で通常稼働に戻した。アサヒ（受注システムの再開まで約2か月）やアスクル（全物流センターでの出荷再開まで約3.5か月）と比べて非常に短い。何が速い復旧を可能にしたか（被害範囲、バックアップ、システム構成、手作業運用への切り替えなど）が公表されれば、大きな教訓になる。
- **「止めて守る」判断の代償**：個人情報と顧客データを守るためにシステムを遮断した結果、冷蔵倉庫と出荷が止まった。低温物流は商品が傷みやすく、停止の影響が大きい。遮断の範囲をどこまで絞れるかを、平時からネットワーク分離の設計で決めておく必要がある。
- **人事情報は機微度が高い**：給与や在留資格まで漏えいした。人事・労務データを保管するサーバーは、アクセス制御と暗号化を特に厳しくすべき。
- **開示の抑制と説明責任のバランス**：捜査との関係で詳細を開示しない方針をとっている。アスクルやアサヒのように、後日、原因と再発防止策を公表するかどうかを注視したい。
