# REXT Holdings（WonderGOO・新星堂ほか） ランサムウェア攻撃（2026年8月）

> 最終確認日: 2026-09-30 ／ 状態: 調査継続中（2026-09-11の第4報時点で情報漏えいの範囲を精査中。加えて2026年6月には連結子会社D&Mで別のランサムウェア被害が発生）

## 3. 攻撃の流れ

### 3.1 D&M（先行事案）
1. 第三者が **VPN機器を経由して** D&Mのファイル共有サーバーに不正アクセス。
2. FAXデータ保存用サーバーがランサムウェアに感染。
3. 過去約2年分（2024年8月〜2026年6月）のFAX受注データ（PDF）に含まれる取引先・顧客の個人情報、633件が外部流出の可能性。

### 3.2 REXT社（本体事案）
公式発表では、侵入経路や攻撃の具体的な手口は明らかにされていない。8月9日にランサムウェアによる不正アクセスが確認され、8月10日の第1報では「現時点の調査において、REXT社が保有するお客様の個人情報や取引先情報等の外部漏えいの可能性を完全には否定できない状況」としていたが、8月14日の第2報では「外部漏えいの可能性は極めて低いと推定」と一度トーンダウンした。しかし9月11日の第4報で、**自社から流出したとみられる情報の一部がインターネット上に掲載されていることを確認**し、漏えいの可能性が再浮上した。

## 4. 被害・影響

### 4.1 業務（REXT社）
- 店舗の臨時休業、部分営業、営業時間の変更。
- キャッシュレス決済等の利用制限、買い取り受付・査定の停止、ポイントサービスの休止。
- EC・オンラインサービスの商品発送遅延、一部サービスの受付停止。
- 全店舗の営業再開は8月16日（発覚から1週間）。サービス制限の解消は9月上旬をめど。

### 4.2 個人情報
- **D&M**：633件（2024年8月〜2026年6月に送信されたFAXデータに含まれる氏名・住所・電話番号など。クレジットカード情報・銀行口座情報は含まれない）。
- **REXT社**：2026-09-11時点で、漏えいまたはそのおそれの範囲は「引き続き調査中」であり、確定件数は非公表。

### 4.3 二次被害
2026-09-11時点で、漏えいしたおそれのある情報が悪用された二次被害（不正利用・不当請求など）は確認されていない。

## 5. 原因

- **D&M**：VPN機器を経由した不正アクセス。VPN機器のセキュリティ対策は完了したと公表。
- **REXT社**：原因は非公表。個人情報保護委員会等の関係行政機関と連携して究明中（2026-09-11時点）。

## 6. 初動対応

**D&M**
- 発覚当日に安全確認のうえ通常業務を再開。
- 該当ファイルサーバーをネットワークから切り離し、VPN機器のセキュリティ対策を実施。

**REXT社**
- 外部専門機関による詳細調査を開始（8/12）。
- 警察・個人情報保護委員会へ報告。
- 店舗ごとに順次復旧作業を実施し、全店舗の営業を1週間で再開。

## 7. 再発防止策

2026-09-30時点で、具体的な技術対策の詳細は公表されていない。第4報（2026-09-11）では次の方針のみが示されている。

- 社外専門機関・関係行政機関（個人情報保護委員会等）と連携した原因究明の徹底
- **システムセキュリティ体制の再構築**
- **全社的な管理強化**による再発防止

D&Mについては、VPN機器のセキュリティ対策の実施とネットワークからの切り離しが完了済みと公表されている。

## 9. 分析: この事例から学ぶこと（暫定）

原因の詳細が非公表のため、現時点では構造的な点に限られる。

- **同一グループで短期間に2件**：2026年6月にD&M（VPN経由）、8月にREXT社（原因非公表）と、同じ企業グループで2か月足らずのうちに別々のランサムウェア被害が発生した。グループ会社ごとにセキュリティ水準がばらついていないか、**グループ横断でのセキュリティ基準の統一**が課題として浮かび上がる。
- **「漏えいの可能性は低い」との説明が覆った**：第2報で一度「可能性は極めら低いと推定」としたが、その後の調査で流出情報の公開を確認した。楽観的な暫定評価を早期に発表することのリスクを示す事例であり、調査途中の説明は「まだ分からない」ことを明確に伝える方が誠実である可能性を示唆する。
- **小売業の停止コスト**：決済制限・買い取り停止・EC発送遅延など、複合的なチャネルへの影響が生じた。店舗・EC・買い取りサービスなど、複数の収益源を持つ小売業ほど、システム停止の影響範囲が広くなる。
