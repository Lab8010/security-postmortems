# ホソカワミクロン クラウドストレージへの不正アクセス（2026年2月）

> 最終確認日: 2026-09-30 ／ 状態: 完了（最終報を公表、2026-03-27）

## 3. 攻撃の流れ（最終報より）

1. **侵入**：攻撃者が、何らかの方法で漏えい・または推測されたID・パスワードを使い、同社が補助的に使用していたクラウドストレージサービス上の **1つのアカウント** に不正ログオンした。
2. **窃取**：そのアカウントにあった個人データを含むファイルが漏えいした。
3. **公開**：2月15日、流出が疑われる電子ファイルがインターネット上に公開されていることを確認した。

社内の基幹システムやネットワークへのランサムウェア展開は確認されておらず、**クラウドストレージという「補助的」な一領域が単独の侵入経路になった**点が特徴。

## 4. 被害・影響

### 4.1 個人情報（最終報、2026-03-27）

| 対象 | 主な項目 | 件数 |
|---|---|---|
| 粉体装置事業の顧客・取引先 | 氏名、性別、住所、メールアドレス、電話番号 | 257件 |
| 従業員（退職者を含む） | 氏名、生年月日、性別、住所、電話番号、メールアドレスなど | 1,470件 |
| 従業員の家族 | 氏名、性別、住所、電話番号、**マイナンバー** | 1件 |

マイナンバーが漏えいした従業員の家族1名には、個別に通知するとした。

### 4.2 事業への影響
業務の停止はなく、影響は軽微だったと公表されている。

## 5. 原因（最終報より）

**補助的に使用していたクラウドストレージサービスの1アカウントへの不正ログオン**。ID・パスワードが漏えいまたは推測されたものと推定される。多要素認証の有無や、そのアカウントの管理状況についての詳細は公表されていない。

## 9. 分析: この事例から学ぶこと

- **「補助的な」クラウドサービスが最大のリスクになりうる**：基幹システムではなく、業務の周辺で使っている**補助的なクラウドストレージ**が単独の侵入経路になった。IT部門が正式に管理していないシステムほど、多要素認証やアクセス制限が手薄になりがちで、いわゆる「シャドーIT」的なリスクが顕在化した典型例といえる。
- **1アカウントの侵害が、マイナンバーを含む漏えいにつながった**：件数自体は約1,728件と他事例より小規模だが、機微性の高いマイナンバーが含まれていた点は重大。少人数の情報しか置いていないクラウドでも、機微情報を扱う場合は最高水準の保護（MFA必須、アクセス元制限、監査ログ）を適用すべき。
- **暗号化なしでも「二重恐喝」型の被害になる**：ランサムウェアによる業務停止がなくても、情報窃取と公開だけで深刻なインシデントになる。バックアップやBCPだけでなく、**データ窃取そのものへの対策（DLP、アクセス監視）**が独立して必要。
- **全社で使っているクラウドサービスの棚卸し**：IT部門が把握していない「補助的な」クラウドアカウントがどれだけあるか、定期的に棚卸しする必要性を示す事例。
