# 損害保険ジャパン Webシステムへの不正アクセス（2025年4月）

> 最終確認日: 2026-09-30 ／ 状態: 金融庁の報告徴求命令に基づき対応中（侵入経路の技術的詳細は非公表）

## 1. 概要

| 項目 | 内容 |
|---|---|
| 企業 | 損害保険ジャパン株式会社 |
| 対象システム | 社内の**Webサブシステム**（各種指標管理を主とする、他システムから独立して稼働するシステム） |
| 侵入期間 | 2025年4月17日〜21日 |
| 顕在化日 | 2025年4月21日に不正アクセスを確認 |
| 攻撃種別 | Webシステムへの不正アクセス（ランサムウェアではない） |
| 個人情報 | 外部から閲覧されたおそれ、または漏えいの可能性があるデータ 最大**約1,748万件**（重複を含む） |
| クレジットカード情報・マイナンバー | 含まれない |
| 行政対応 | 2025年6月12日、金融庁から**保険業法・個人情報保護法に基づく報告徴求命令**を受領 |

## 3. 攻撃の流れ

公式発表では、侵入の具体的な手法（認証情報の窃取か、脆弱性の悪用か等）は明らかにされていない。判明している範囲は次のとおり。

1. 社内の**Webサブシステム**（各種指標管理用、他システムから独立）が第三者による不正アクセスを受けた。
2. フォレンジック調査の結果、**4月17日から21日までの期間**、外部から侵入した第三者が顧客情報にアクセスできる状態になっていたと推測される。
3. 4月21日に不正アクセスを確認し、直ちに当該システムを停止、ネットワークを遮断した。
4. 独立して稼働するWebシステムであったため、他のシステムへの影響はなかった。

## 4. 被害・影響

### 4.1 外部から閲覧されたおそれ、または漏えいの可能性があるデータ（2025-06-11時点）

**顧客関連データ**

| 区分 | 件数 |
|---|---|
| 「氏名」「連絡先」「証券番号」が記載されたデータ | 約337万件 |
| 「氏名」「証券番号」のみ（連絡先なし） | 約187万件 |
| 「連絡先」「証券番号」のみ（氏名なし） | 約119万件 |
| 上記以外（氏名のみ、住所のみなど） | 約83万件 |

**代理店関連データ**：約178万件

**その他**：証券番号・事故番号のみで、データベースと照合しないと個人を特定できないデータが約844万件。

**漏えいの可能性がある情報の項目**：氏名、生年月日、性別、住所、電話番号、メールアドレス、金融機関口座情報（1,638件）、証券番号・事故番号、被保険者名、保険募集人氏名・募集人ID・生年月日（代理店関連、9,366件）。**すべての情報が同一ファイルで閲覧可能な状態だったものはない**。マイナンバーカード・クレジットカード情報は含まれない。

### 4.2 二次被害
2025年6月時点で、情報が不正利用された事実は確認されていない。

## 5. 原因（公式発表の範囲）

技術的な侵入経路（認証情報の窃取、脆弱性の悪用など）は公表されていない。同社は「他システムに同様の脆弱性がないこと」を確認したと発表しており、Webサブシステム固有の問題だったことを示唆しているが、詳細は明らかにされていない。

## 6. 初動対応

- 検知後、Webシステムを停止し、ネットワーク遮断などの初動対応を即座に実施した。
- 独立稼働のシステムであることを確認し、他システムへの影響がないことを確認した。
- 所管警察署へ届け出た。
- 他システムに同様の脆弱性がないことを確認し、Webサイトの不正アクセス監視を強化した。
- 対象の可能性がある顧客に順次、個別に連絡した。

## 7. 再発防止策（2025-06-11時点で公表されている範囲）

- 他システムに同様の脆弱性がないことの確認（実施済み）
- Webサイトの不正アクセスの監視強化（実施済み）
- 金融庁の報告徴求命令に基づき、原因分析と再発防止策を報告する予定（詳細は2026-09-30時点で確認できた公式資料には記載なし）

## 8. 未公表・不明な点

## 9. 分析: この事例から学ぶこと

- **「独立したサブシステム」が最大級の漏えい規模を生んだ**：基幹システムではなく、指標管理用の周辺システムから、保険業界では際立って大きい約1,748万件（重複含む）の情報が対象になった。**「重要度が低い」と見なされがちな周辺システムに、大量の顧客データが集積していないか**の棚卸しが必要になる。ホソカワミクロン（補助的なクラウド）と同様の構図。
- **侵入から検知まで最短で完結**：侵入期間は4月17日〜21日のわずか5日間で、同日中に検知・遮断している。これは掲載事例の中でも検知が早い部類に入り、多くの事例で「数週間〜数年」かかっていることと対照的である。ただし、なぜこれほど早く検知できたかの詳細（監視体制）は公表されていない。
- **金融機関としての規制対応**：金融庁の報告徴求命令という、保険業法に基づく行政手続きが発動した。アフラック（生命保険）と同様、金融機関は個人情報保護法に加えて業法上の監督も受ける点が、他業種の事例と異なる。
- **技術的な原因が非公表**：さくらインターネットと同様、侵入の技術的な手法は明らかにされていない。金融機関特有の「二次被害防止・模倣攻撃防止」への配慮が、開示の抑制につながっている可能性がある。
