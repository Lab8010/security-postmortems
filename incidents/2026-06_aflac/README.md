# アフラック生命保険 契約者向けシステムへの不正アクセス（2026年6月）

> 最終確認日: 2026-09-30 ／ 状態: 調査結果・再発防止策を公表済み（2026-07-31）。対象システムの再開時期は未定（同日時点）

| 項目 | 内容 |
|---|---|

## 3. 攻撃の流れ（公式発表の範囲）

- 攻撃者は「オンライン相談」と「アフラック よりそうネット」に対し、**通常の利用と同じ形式のアクセス** で、個人情報を大量に照会した。
- システムには不正アクセスを検知・遮断する機能があったが、通常の利用と見分けがつかず、すぐには検知できなかった。
- 短時間の大量照会を監視・制御する機能が不足しており、大量の情報が引き出された。
- 社内と外部専門機関の調査で、この2つ以外のシステムでは同種・類似の漏えいはないことを確認した。

> 攻撃の具体的な手口（認証の突破方法、照会の方法など）は公表されていない。

## 4. 被害・影響

- 約440万人の契約者情報、約22万人の口座情報、約4万店の代理店情報が漏えいした。
- 契約者向けサイトとオンライン相談を停止した。保険金・給付金の請求などはコールセンターで受け付けている。
- 口座情報の漏えいを受け、二次被害を防ぐために関係する金融機関と連携した。
- 現時点で不正利用は確認されていない。

## 5. 原因（2026-07-31 公表）

1. 「オンライン相談」と「アフラック よりそうネット」で、今回の攻撃に使われた **アクセスとデータ照会の手口に対する制御が不十分** だった。
2. 不正アクセスの検知・遮断機能はあったが、アクセス形式が **通常の利用と同様** だったため、すぐに検知できなかった。
3. **短時間に大量のデータ照会があった場合に監視・制御する機能が不足** していた。
4. システム設計時のセキュリティレビューやリリース前の侵入テストは実施していたが、**今回の手口のリスクを想定できていなかった**。

## 6. 初動対応

- 判明当日に不正アクセスを遮断し、関連システムを停止した。
- 金融庁・警察へ報告した。
- 口座情報が漏えいした契約者を優先して、個別に通知した。
- 金融機関と連携し、口座の不正利用を監視した。

## 7. 再発防止策（2026-07-31 公表）

| # | 対策 | 内容 |
|---|---|---|
| 1 | アクセスとデータ照会の制御を強化 | システムにアクセスする際の **認証** と、データを照会する際の **認可** を強化する |
| 2 | 大量アクセスの監視と制御を強化 | アプリケーションとセキュリティ機器の両方で、大量アクセスへの監視・制御を強化する |
| 3 | 設計レビューと侵入テストを強化 | 不正アクセスのリスクを多層的に分析してセキュリティ要件を最新化し、レビューの実効性と侵入テストを強化する |
| 4 | 情報セキュリティ管理態勢を強化 | 人員の増強と体制の強化。セキュリティ標準・基準の再整備、レビューの強化、リリース前の検証の強化、**リリース後の監視体制と継続的改善の強化** |

- 各施策の進捗と有効性を継続的にモニタリングし、原因をさらに深掘りして、必要なら追加の施策を実行する。

## 9. 分析: この事例から学ぶこと

- **ランサムウェアではなく「正規の機能の悪用」**：他の事例と違い、システムは壊されず、Webアプリの機能を使って情報が引き出された。認証（誰か）だけでなく、**認可（その人がそのデータを見てよいか）** を照会のたびに確認する設計が要る。一般には IDOR／BOLA（他人のIDを指定するとデータが見えてしまう欠陥）と呼ばれる類型への対策が、この再発防止策の「データ照会時の認可の強化」にあたると考えられる（手口は非公表のため推測）。
- **「正常に見える」攻撃は、量で見つける**：1件ずつは正常なアクセスでも、短時間に大量の照会があれば異常。利用者ごと・代理店ごとの照会数の上限やレート制限、異常な照会パターンのアラートが有効。
- **侵入テストは「想定した手口」しか見つけない**：レビューもテストもしていたのに、想定外の手口だった。脅威モデリングを定期的に見直し、ビジネスロジックの悪用まで含めたテストを行う必要がある。
- **発見まで2週間**：最初の漏えい（6/10）から判明（6/25）まで約2週間。リリース後の監視（アプリログの分析）を強化するという対策は、この点への反省と読める。
- **代理店向けツールも入口になる**：「オンライン相談」は代理店が使うツール。社外の利用者に開いた機能ほど、照会できるデータの範囲を最小限にする。
- **経営責任の明示**：役員の報酬返納まで公表しており、金融機関として説明責任を果たす姿勢が見える。
