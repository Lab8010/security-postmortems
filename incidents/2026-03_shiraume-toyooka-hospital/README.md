# 白梅豊岡病院 ランサムウェア攻撃（2026年3月）

> 最終確認日: 2026-09-30 ／ 状態: 第4報まで公表。厚生労働省の初動対応支援チームが派遣された

## 1. 概要

| 項目 | 内容 |
|---|---|
| 法人 | 医療法人社団白梅会 白梅豊岡病院（静岡県磐田市。介護老人保健施設「白梅豊岡ケアホーム」等を併設） |
| 顕在化日 | 2026年3月1日（日）、電子カルテの不具合を日直の事務職員が確認 |

| 個人情報 | 患者・利用者とその家族、関係者の氏名・住所・電話番号・病名等が漏えい。ダークウェブに「フルデータ」が公開された |
| 特色 | **厚生労働省の初動対応支援チームが派遣**され、調査・助言を受けながら対応した数少ない事例 |

## 3. 攻撃の流れ

厚生労働省の初動対応支援チームの調査により、**VPNの脆弱性等**が侵入経路として指摘された。具体的な機器名や脆弱性の詳細は公式には公表されていない。攻撃の結果、電子カルテシステムを含む院内システムがランサムウェアに感染し、閲覧不能になった。

## 4. 被害・影響

### 4.1 業務
電子カルテシステムをはじめとする院内システムが利用できなくなった。具体的な業務停止期間・診療への影響の詳細は、確認できた公式発表には明記されていない。

### 4.2 個人情報

| 段階 | 内容 |
|---|---|
| 第1報（3/3） | 病院を利用した患者・家族・関係者の氏名・住所・病名・電話番号・携帯電話番号・メールアドレス等の**漏えいの可能性**を指摘された |
| 第2報（3/4） | 病院・ケアホーム利用者とその家族・関係者の氏名・住所・病名・電話番号・携帯電話番号の**漏えいを確認** |
| 第3報（3/6） | ダークウェブ上に、利用者・家族・関係者の**「フルデータ」が公開**されたとの情報提供を受ける |
| 第4報（3/26） | 漏えいが確認された対象者から順次、内容を記載した文書の発送を開始 |

- 漏えいした情報には、氏名・住所・電話番号に加えて**病名**という医療機関特有の機微情報が含まれる。
- 具体的な確定件数は、確認できた公式発表の範囲では明示されていない。

### 4.3 二次被害への注意喚起
不審な電話・SMSが送信される危険性について、繰り返し注意喚起を行っている。

## 5. 原因

厚生労働省初動対応支援チームの調査により、**VPNの脆弱性等**の指摘を受けたと第4報で公表されている。それ以上の技術的詳細（機種、CVE番号など）は非公表。

## 6. 初動対応

- 不具合の確認後、直ちに院内の全情報通信機器のネットワークを遮断した。
- 静岡県警察本部、厚生労働省医政局、静岡県西部保健所に即日〜翌日に報告した。
- 白梅会グループ内に対策本部を設置し、厚生労働省に初動対応支援チームの派遣を要請した。
- 初動対応支援チームの助言に基づき、グループ全施設で二次被害防止の緊急対策を実施した。
- 専用のコールセンターを設置し、対象者へ個別に文書を発送した。

## 7. 再発防止策

第4報までに確認できた公式発表では、次の方針レベルの言及にとどまる。

- 国の指針・ガイドラインを遵守した情報システムの構築
- 職員へのセキュリティ教育の徹底

VPN脆弱性への具体的な対処（機器の更新、廃止、多要素認証の導入など）についての詳細な記載は、確認できた公式発表の範囲にはない。

## 9. 分析: この事例から学ぶこと

- **医療機関特有の初動対応**：厚生労働省の初動対応支援チームが派遣され、県警のサイバー捜査課とも連携した。これは民間企業の事例には見られない、医療分野特有の公的支援の枠組みであり、医療機関のインシデント対応体制を考えるうえで参考になる。
- **VPNが再び侵入口に**：名古屋港、イセトー、アサヒ、穴吹ハウジングサービス、サンリオに続き、**VPN（またはリモートアクセス機器）**が侵入口になった。業種・組織規模を問わず、VPN機器の管理が最重要の対策であることが、これで7事例目の裏付けとなった。
- **「病名」という機微情報の漏えい**：氏名・住所に加えて病名が漏えいした。医療情報は要配慮個人情報（センシティブ情報）に該当し、他の業種の情報漏えいよりも本人への心理的・社会的な影響が大きい。
- **中小規模の医療法人のセキュリティ体制**：白梅会は病院・介護施設を運営する医療法人社団であり、大企業と比べて自前のセキュリティ体制を持ちにくい組織である可能性が高い。厚生労働省の支援チームのような公的な仕組みが、こうした組織にとって実務上重要な役割を果たすことを示す。
- **開示の透明性**：経緯を「対応経緯の別表」として時系列で丁寧に公開している点は、他の事例と比べても分かりやすい。一方で、原因の技術的詳細や漏えい件数の確定値は明らかにされておらず、情報公開の範囲には限界がある。
