# 穴吹ハウジングサービス（あなぶきハウジンググループ） ランサムウェア攻撃（2026年2月）

> 最終確認日: 2026-09-30 ／ 状態: 完了（第6報で件数確定・再発防止策を公表、2026-05-21）

## 1. 概要

| 項目 | 内容 |
|---|---|
| 企業 | 株式会社穴吹ハウジングサービスを中核とする、あなぶきハウジンググループ（マンション管理・賃貸管理） |

| 攻撃者 | 公式発表では明示なし。ランサムウェアグループ「Qilin」が犯行声明を出したと報じられている（報道ベース） |

## 3. 攻撃の流れ（第5報・第6報より）

1. **初期侵入**：グループ会社の通信機器（ネットワーク機器）の脆弱性を突かれて社内ネットワークに侵入された。
2. **横展開**：侵入後、**業務時間外を中心に** リモートデスクトップなどを使って複数のサーバーへのログインを試行した。
3. **権限奪取**：管理者権限を不正に奪取し、ネットワーク全体に侵入範囲を拡大した。
4. **暗号化**：複数のサーバーにランサムウェアを展開し、ファイルを暗号化した。
5. **情報公開**：攻撃者が窃取した情報を公開し、そこに自社に関連する情報が含まれていることを事後に確認した。

## 4. 被害・影響

### 4.1 個人情報

| 段階 | 件数 | 時点 |
|---|---|---|
| 漏えいのおそれ（最大） | 約49万6,000件 | 2026-03-09（第4報） |
| ファイル単位の流出確認 | 約21万件のファイル | 2026-04-03（第5報） |
| **漏えい確定件数** | **207,773件** | 2026-05-21（第6報、最終） |

主な項目は氏名・電話番号など。対象者ごとに含まれる情報は異なる。松山市営住宅の入居者については、氏名・団地名・部屋番号・生年月日などが含まれ、生活保護や障害者手帳の該当状況を含む情報も一部漏えいした（報道ベース）。

- 不動産管理・仲介業務の顧客情報、取引先情報、役員・従業員（元従業員を含む）の情報が対象。
- 二次被害（不正利用や金銭的被害）は、2026-05-21時点で確認されていない。

### 4.2 業務

- マンション管理組合運営業務、賃貸管理業務、重要事項調査報告書の発行など、一部業務に発行手続きの遅延が生じた。
- 営業活動自体は発生当初から継続していた。

## 5. 原因（第5報・第6報より）

**グループ会社のネットワーク機器の脆弱性を突かれて侵入を許し、その後の横展開を抑止できなかったこと**が発生原因。具体的な機器名・脆弱性の詳細は、被害拡大防止の観点から公表を差し控えている。

## 6. 初動対応

- 発見当日にシステムを隔離し、ネットワークを遮断した。
- 対策本部を設置し、配下に「業務継続」「社内対応」「データ保全」「システム再構築」「広報」の5チームを置いた。
- 外部専門機関（フォレンジック調査）と、数十名規模の社外エンジニアの協力体制を構築した。
- 警察、個人情報保護委員会、国土交通省の地方整備局、財務局など関係当局に報告した。
- 専用のコールセンター（2026-03-13設置）で対象者からの問い合わせに対応した。

## 7. 再発防止策（2026-05-21 公表）

### 7.1 旧IT環境の廃棄と手当て（実施済み）
- 従来のネットワークを **VPN機器も含めて全て完全に利用停止**
- 被害の程度を問わず **PCを全台入れ替え**
- クラウドサービスのアクセスの健全性確保（ユーザーIDの棚卸し、アクセスログ確認、パスワード変更、対応システムへの多要素認証導入）

### 7.2 ゼロトラストの概念を採り入れたIT環境への移行
- 認証・権限管理の基盤を **オンプレミスからクラウド型へ移行**し、多要素認証とID統合を推進
- エンドポイント（PC・サーバー）の監視を強化（第三者評価機関で最高評価のEDR製品へ刷新、**24時間365日の監視体制**を構築）
- **SASE導入によるゼロトラストネットワークへの移行**で、内部侵入後の横展開・不正アクセスの拡大を防止
- 社内システム用にセキュアなプライベートクラウド環境を構築（内部セグメントの分離、多要素認証の強制、脆弱性管理、バックアップ方式の見直し）

### 7.3 IT・セキュリティのガバナンス強化
- セキュリティ教育を実施し、「人」を狙った攻撃（フィッシングなど）への耐性を向上
- ISMSやCSIRTなど、セキュリティ関連の規範・体制・運用を再構築

## 9. 分析: この事例から学ぶこと

- **境界防御からゼロトラストへの転換を明言**：「外は危険、中は安全」という従来モデルの限界を認め、VPN機器の全廃止とゼロトラストへの移行を打ち出した。これはアサヒやイセトーと同じ選択であり、**VPN機器を侵入口にされた企業が共通してVPNの廃止に行き着く**という業界的な傾向が見える。
- **横展開を止められなかった**：侵入後、業務時間外に複数サーバーへログインを試行し、管理者権限を奪って全体に広がった。この動きはアサヒの事例（約10日間、業務時間外中心の偵察）と酷似している。業務時間外の異常なログイン試行を検知する仕組みの重要性が、複数事例で裏付けられている。
- **委託元・公的機関への波及**：マンション管理という業態上、委託元である管理組合や自治体（松山市営住宅）の入居者情報まで漏えいした。イセトーと同様、BtoB受託業務は自社の顧客だけでなく、その先の個人にまで影響が及ぶ。
- **件数が段階的に判明した**：おそれ49.6万件 → ファイル21万件 → 確定20.8万件、と3段階で情報が更新された。最終的な確定件数が当初の「おそれ」より少なくなった点は、他の事例（アサヒ、アスクル）とは逆の推移であり、**過大に見積もった上で精査していく開示姿勢**として参考になる。
- **段階的なチーム編成**：対策本部の下に5つの役割別チームを即日設置した体制は、インシデント対応の組織づくりの一例として具体的で参考になる。
